    Split

    Group trip expense app with its own design system

    Friends log what they paid and split it evenly, by custom amounts, or item by item from a receipt. Split shows who owes whom and the fewest payments to settle up. I built it for a trip to Chicago, used it there, then rebuilt it into a multi-trip app.

About this site

Build
Plain HTML and CSS with a few lines of JavaScript for the theme switch. No framework and no build step.
Tokens
Raw values (colors, type sizes, spacing) live in one layer of CSS custom properties. Components use only semantic tokens such as --color-surface, so the dark theme swaps one set of tokens.
Accessibility
Semantic landmarks and headings, a skip link, visible focus rings, text contrast above WCAG AA in both themes, 44 px touch targets, and no motion when your system asks for reduced motion.
Performance
Screenshots are WebP at about 40 KB each, with fixed sizes so nothing shifts while they load.
